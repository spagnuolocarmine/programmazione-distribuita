# Oggetti Remoti con Java Socket 


## Esercizio 1
Sviluppare l'esempio di oggetti remoti con Java Socket, come descritto nel libro "Programmazione con Oggetti Distribuiti: Java RMI" (Capitolo 2).


## Esercizio 2
Modificare l'esempio di oggetti remoti con Java Socket, come descritto nel libro "Programmazione con Oggetti Distribuiti: Java RMI" (Capitolo 2), in modo da poter gestire più client contemporaneamente. In particolare, il server deve essere in grado di gestire più richieste di connessione da parte dei client, creando un nuovo thread per ogni connessione accettata, gestendo le richieste in modo concorrente.
