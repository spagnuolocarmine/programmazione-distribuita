# Oggetti Remoti con Java Socket 


## Esercizio 1
Sviluppare l'esempio di oggetti remoti con Java Socket, come descritto nel libro "Programmazione con Oggetti Distribuiti: Java RMI" (Capitolo 2).


## Esercizio 2
Modificare l'esempio di oggetti remoti con Java Socket, come descritto nel libro "Programmazione con Oggetti Distribuiti: Java RMI" (Capitolo 2), in modo da poter gestire più client contemporaneamente. In particolare, il server deve essere in grado di gestire più richieste di connessione da parte dei client, creando un nuovo thread per ogni connessione accettata, gestendo le richieste in modo concorrente.

## Esercizio 3
Modificare l'esempio di oggetti remoti con Java Socket, per la realizzazione della gestione di una libreria musicale. In particolare, il server deve essere in grado di gestire più richieste di connessione da parte dei client, creando un nuovo thread per ogni connessione accettata, gestendo le richieste in modo concorrente. Il server deve essere in grado di gestire le seguenti operazioni:
- Aggiungere un nuovo brano musicale alla libreria;
- Rimuovere un brano musicale dalla libreria;
- Visualizzare la lista dei brani musicali presenti nella libreria;
- Ricercare un brano musicale per titolo o per artista.
- Ottenere il link al brano musicale per poterlo ascoltare in streaming.
